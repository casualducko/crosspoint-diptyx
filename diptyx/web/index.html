CrossPoint for the Diptyx

Install the open-source CrossPoint reader on your Diptyx dual-screen e-reader, straight from the browser. Unofficial · early beta

This browser can't flash devices. Web flashing needs Chrome, Edge or another Chromium browser on a desktop computer (Windows, macOS or Linux). Safari, Firefox and phones can't do it. You can still use the flash script.
This page must be opened over HTTPS (or localhost) for the browser to allow USB access.

1 Put the Diptyx in download mode

  1. Unplug USB and switch the Diptyx completely off: hold the power button for about 20 seconds.
  2. Hold the centre button pressed in.
  3. While holding it, plug in the USB-C data cable. Keep holding for about 3 seconds, then let go.

The screens don't change in download mode, that's normal. Use a cable that carries data (a charge-only cable won't work).

2 Connect

Click the button, choose USB JTAG/serial debug unit in the list, and wait for the checks.

    3 Install

    Installing writes only the app slot (0x10000). Your bootloader, partition table, settings and books are not touched.

    Other options

    The stock image is downloaded from the Diptyx makers' repository and checked against a known checksum. A file of your own must be an app image for the Diptyx, not a full-flash image.

    Working…

      Keep the cable plugged in and this tab open until it says it's done.

      Technical log 
      
    
  
      

  
      
    Having trouble?
    
        
      
      • The Diptyx isn't in the list. It must be in download mode (step 1) and plugged in with a data cable. Try another USB port, and avoid hubs.
        • 
      
      • "Busy" or "could not open". Close other tabs or apps that use the Diptyx's serial port (serial monitors, other flashers), then unplug and redo step 1.
        • 
      
      • It says my partition table is not the stock one. This flasher only supports Diptyx units with the original layout and refuses to write anything otherwise. Nothing was changed.
        • 
      
      • After flashing it sits in download mode. Unplug, switch off for 20 seconds, then plug in again without touching the centre button.
        • 
      
      • Linux: if the browser can't open the port, add yourself to the dialout (Debian/Ubuntu) or uucp (Arch/Fedora) group, or install the udev rule from the guide, then log out and in.
        • 
      
      • Back to stock any time: use Other options › Go back to the stock Diptyx firmware above.
