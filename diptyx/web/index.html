CrossPoint for the Diptyx e-reader

Unofficial port of the CrossPoint reader firmware to the Diptyx dual-screen e-reader. This page flashes it from your browser. It needs Chrome, Edge or another Chromium browser (Windows, macOS or Linux). Safari and Firefox cannot do this; use the flash script instead.

Back up first. This writes only the app region (0x10000) and leaves your bootloader, partition table and settings alone, but you should still keep a copy of your current firmware. This page does not check that your device has the stock partition layout; the flash script does (python flash.py check). The flash script can make one: python flash.py backup (see the guide). Going back to the stock firmware is described there too.
  1. Switch the Diptyx fully off (hold the power button ~20 s), hold the centre joystick pressed in, and plug in the USB-C data cable while holding it. Release after ~3 seconds.
  2. Click the button below, pick the USB JTAG/serial debug unit port, and follow the prompts.
  3. When it finishes, unplug the cable and plug it in again without touching the joystick.
This browser cannot flash devices. Use Chrome or Edge, or the flash script. Web flashing needs HTTPS (this page).
